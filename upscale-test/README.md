# Upscale test
1. Put one video in `videos/` (e.g. `videos/clip1.mp4`) and commit.
2. Actions tab > "Upscale test" > Run workflow.
3. Enter `clip1.mp4`, frames `5`, model `RealESRGAN_x4plus`.
4. Read the "Seconds per frame" in the run summary.
5. Rerun with frames `0` to do the whole clip. Download the result from the run's Artifacts.
